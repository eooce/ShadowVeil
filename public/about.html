关于

ShadowVeil 是一个开源的在线代码混淆平台：JavaScript 基于 javascript-obfuscator（与 js-obfuscator 等在线工具同源），Python 与 Shell 由自研引擎驱动 —— 只做词法与编码级变换，绝不执行你的代码。混淆在服务端瞬时完成，源码不落盘、不外发。

三套引擎

JavaScript：三档强度（轻 / 中 / 高），控制流扁平化与字符串加密；Python：词法混淆 + 多层 zlib / base64 自解压外壳；Shell：base64 直解执行，或 bashfuscator 风格的多层编码变换。

安全边界

混淆过程纯文本变换，无 eval、无子进程执行用户代码；数据库只记录体积与耗时等元数据；每个请求都有 requestId 便于审计。

开放生态

所有能力都通过 RESTful API 开放，带 Key 即可程序化调用；配置可写入 URL 分享，团队协作零成本。
